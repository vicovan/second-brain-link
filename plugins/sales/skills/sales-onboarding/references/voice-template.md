# Voice — how messages should sound

Written by `sales-onboarding` into `<sales layer>/profile/voice.md`, from the brain's own voice
layer (posts, comments) and what the seller says. Every message is written in this voice.

- Short sentences. One idea per paragraph. No "I hope this finds you well".
- Plain words: the buyer's terms, not ours.
- One question per message, and it is easy to answer.
- Never: fake urgency, fake familiarity, "just bumping this", a calendar link in a first email.
