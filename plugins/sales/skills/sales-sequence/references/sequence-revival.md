# Revival — reopen a lost deal

For an account where a deal stalled or was lost and someone there still holds a real tie.
Open with what changed since the deal stopped — never with a pitch, never pretending the gap did not happen.

| n | channel | wait_days | kind | requires | brief |
|---|---|---|---|---|---|
| 1 | email | 0 | first | | name the old deal and the reason it stopped (from the deal note); one thing that changed since; one question |
| 2 | linkedin_invite | 3 | connect | social | only if not already connected; a one-line note that names the old project |
| 3 | email | 4 | follow-up | | a useful detail tied to their reason for stopping; no "just bumping this" |
| 4 | linkedin_dm | 5 | dm | social, connected | two sentences; the same question, shorter |
| 5 | email | 7 | breakup | | close the loop politely; leave the door open; ask who owns this now if not them |
