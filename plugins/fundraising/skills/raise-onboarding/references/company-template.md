# company.md — template

The source of truth for every claim about the company. `lint_claims.py` refuses any number in a
draft that does not appear in this file or the other profile files, and any term in
**Do not claim**.

```markdown
---
type: fundraising-profile
title: Company
---

# Example Payments

## One line
Payment-orchestration API for marketplaces that settle in several currencies.

## Product truth (shipped, checkable)
- 3 payment rails integrated; 140 automated tests passing.
- Live with 2 design partners (unpaid pilots).

## Traction
- Pre-revenue. 0 raised.

## Market (with sources)
- Figures here only with a link; the plan will not repeat an unsourced market size.

## Do not claim
- revenue — pre-revenue
- customers — pilots are design partners, not customers
- bank partnership — none signed
```
