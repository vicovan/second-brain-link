# Form patterns

| Platform | Shape | Watch for |
|---|---|---|
| Typeform | one question per screen; Enter advances | the value must register before advancing; limits shown only on focus |
| Tally | single page or pages; counters often unit-less | test the unit; file uploads inline |
| Fillout | multi-step | per-step validation hides errors until submit |
| Google Forms | sections; "Next" buttons | required markers; a signed-in Google account may be required for uploads |
| Airtable form | single page | a shared VIEW link is not a form — only `airtable.com/app…/shr…` pages built as forms accept input |
| HubSpot | embedded on the fund's site | hidden fields; do not touch fields that are not visible |
| Program portals (accounts) | login wall | stop — the founder signs in and can then ask the agent to fill page by page in their session |

Common questions and where their answers live:

| Question | Source |
|---|---|
| One-liner / what do you do | `company.md` one line |
