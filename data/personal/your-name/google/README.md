# Google Takeout export

Drop your unzipped **Takeout** folder here (or pass the `.zip`). Contents are
git-ignored. Builds contacts → people, Calendar → events, YouTube → interests, and
Google Maps (Saved Places / Reviews) → the `85-places/` layer.

Download: [takeout.google.com](https://takeout.google.com) → select **Contacts,
Calendar, YouTube, Maps, Profile** → create export.
