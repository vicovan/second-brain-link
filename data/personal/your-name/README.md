# data/personal/your-name/ — a template identity (rename me)

Example identity folder showing the layout. **Rename it to your actual name** —
e.g. `data/personal/jane/` — then drop each export into the matching source
subfolder. The folder name becomes your digital-twin brain at
`vault/personal/<name>-brain/`.

Sources: `linkedin/`, `facebook/`, `instagram/`, `google/` (use the one(s) you
have — one is enough; LinkedIn is the richest). Everything you add here is
git-ignored; only these placeholder READMEs are tracked. While the folder holds
only READMEs the builder skips it, so it's safe to leave in place until you add data.

Privacy: third-party emails/phones are never written and message bodies are never
read; the raw exports you drop here may still contain personal data, which is why
this whole tree stays git-ignored.
